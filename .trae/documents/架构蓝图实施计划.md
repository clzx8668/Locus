## 任务一：完成 Phase 1 底座（数据库同步基础 + PocketBase 集成）

### 1.1 数据库升级 v8→v10（合并 sync + is_deleted）
**文件**：`lib/core/database/database.dart`

由于之前的 sync 代码已丢失，本次一次性完成两个版本的迁移：

**v8→v9**（sync 基础字段）：
- 添加依赖 `uuid: ^4.5.1` 到 `pubspec.yaml`
- 为 10 张业务表添加：
  - `syncUuid` (TextColumn, nullable, UUID v4)
  - `syncStatus` (IntColumn, 0=local/1=synced/2=updated)
- 为 `chat_messages` / `knowledge_files` / `activities` 添加 `updatedAt` 列
- 编写 `_migrateV9()` ALTER TABLE 迁移
- 所有 `insert*()` 方法生成 syncUuid
- 所有 `update*()` 方法将 syncStatus 标记为 2

**v9→v10**（软删除）：
- 为全部 10 张表添加 `isDeleted` (BoolColumn, default false)
- 编写 `_migrateV10()` 迁移
- 将物理 `DELETE` 改为软删除：`delete*()` 设置 `is_deleted=1`
- 所有 `watch*()` / `get*()` 查询添加 `WHERE is_deleted = 0`
- 运行 `dart run build_runner build --delete-conflicting-outputs`

### 1.2 LAN 同步基础设施
**文件**：`lib/core/sync/` (全部新建)

- `sync_protocol.dart` — SyncChange / PushPullRequest / DeviceInfo
- `sync_database_ext.dart` — 变更查询 / 远程写入 / 标记已同步 / LWW 冲突
- `sync_server.dart` — PC 端 HTTP Server (port 8765)
- `sync_client.dart` — 手机端 HTTP Client (Dio)
- `discovery_service.dart` — UDP 广播设备发现 (port 9876)
- `sync_service.dart` — SyncService (ChangeNotifier, Server/Client/Disabled 模式)

### 1.3 DI 与 UI 集成
- `service_locator.dart` 注册 SyncService 单例 + 启动初始化
- `settings_page.dart` 增加 "Data Sync" 分区：模式选择 + 状态 + 设备列表 + 手动同步

### 1.4 PocketBase Schema 定义
**文件**：`server/pocketbase/schema.md`（文档，非可执行代码）

记录 10 个 Collections 的字段定义和索引，供 Admin UI 手动创建时参考。

### 1.5 PocketBase Dart SDK 集成（预留）
- 添加 `pocketbase: ^0.18.0` 到 `pubspec.yaml`
- 创建 `lib/core/sync/pocketbase_adapter.dart`：PocketBase 连接 + CRUD 映射
- SyncService 新增 `SyncTarget.pocketbase` 枚举值（当前阶段先定义接口，Phase 2 彻底打通）

## 任务二：Zvec 本地 AI 引擎接入（Phase 2）

### 2.1 Zvec 集成
**文件**：`pubspec.yaml` + `lib/core/zvec/`（新建）

- 添加 Zvec Dart SDK 依赖（`zvec: ^x.x.x`，版本待定）
- 创建 `ZvecService`：
  - 初始化本地 Zvec 实例
  - 创建 Collection：`locus_notes`（schema: content TEXT, embedding VECTOR, note_id TEXT, chunk_index INT）
  - 建立 FTS 索引：`content` 字段
  - `MultiQuery` 接口封装：同时执行向量检索 + FTS 检索，RRF 融合排序

### 2.2 ETL 管道
**文件**：`lib/core/services/embedding_etl.dart`（新建）

当本地 SQLCipher 数据变更后：
1. 扫描 `knowledge_files` / `chat_messages` 中的新文本
2. 调用 `EmbeddingService.getEmbedding()` 生成向量
3. 写入 Zvec Collection（含 `note_id` metadata）
4. 更新 `VectorStorage` 表标记"已索引"

### 2.3 替换现有向量搜索
**文件**：`lib/core/services/embedding_service.dart`（重构）

- 保留 `getEmbedding()` 云端调用逻辑
- `search()` 方法改为优先调用 Zvec `MultiQuery`（本地毫秒级）
- 降级方案：Zvec 不可用时回退到 SQLite 暴力搜索

## 任务三：AI Router 重构 + Text-to-SQL（Phase 3）

### 3.1 AI Router 重建
**文件**：`lib/core/services/ai_router.dart`（新建）

```dart
enum QueryIntent { semantic, structured, mixed }

class AiRouter {
  Future<QueryIntent> classifyIntent(String query);
  Future<SearchResult> routeAndSearch(String query);
}
```

- 意图分类：LLM Prompt（少样本分类）
- 语义/关键词 → 调用 `ZvecService.multiQuery()`
- 结构类 → 调用 `TextToSqlService`
- 混合类 → 并发 + 合并

### 3.2 Text-to-SQL 服务
**文件**：`lib/core/services/text_to_sql_service.dart`（新建）

- `SchemaInjector`：将 SQLCipher 表结构转 JSON 注入 Prompt
- `SqlGenerator`：LLM 生成 SELECT
- `SqlGuard`：拦截非 SELECT（DELETE/DROP/INSERT → 拒绝）
- `SqlExecutor`：本地执行 SELECT → `List<Map>`

### 3.3 整合到 ChatPage
**文件**：`lib/features/chat/presentation/chat_page.dart`

`_gatherContext()` 改为：AiRouter.classify → routeAndSearch → 注入 LLM Context
