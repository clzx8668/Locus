# Twenty 公司详情侧栏与表格设计参数整理

> 说明：由于当前不是原始 Figma 文件，而是截图，所以文档会区分「可从截图直接确认」与「按视觉比例推断」两类参数。

## 1. 设计对象概述

这是一个典型的 **CRM 实体详情侧栏 / Field Panel**，用于展示公司（Company）资料、关联记录和扩展信息。

整体风格关键词：

- 高信息密度
- 低饱和中性色
- 轻边框分隔
- 模块化列表
- 适合桌面端右侧详情面板

## 3. 按截图推断的版式参数

以下参数为基于画面比例的视觉推断，适合直接作为复刻参考值。

### 3.1 整体布局结构

面板结构大致分为 4 层：

1. 顶部实体摘要区
2. 基础字段信息区
3. 可折叠更多信息入口
4. 关联模块区（Holdings / Opportunities / People）

推荐结构：

```text
FieldPanel
├─ Summary Header
├─ Fields List
├─ More Toggle
├─ Section: Holdings
├─ Section: Opportunities
└─ Section: People
```

### 3.2 版式建议参数

| 项目 | 建议值 |
|---|---|
| 面板宽度 | `320px` |
| 内容横向内边距 | `16px` |
| 顶部摘要区上下留白 | `24px ~ 28px` |
| 模块之间分隔线 | `1px` |
| 模块标题区高度 | `44px ~ 48px` |

| Section 项左右 padding | `16px` |
| Section 内列表项高度 | `32px ~ 36px` |

## 4. 视觉层级拆解

### 4.1 顶部摘要区

顶部摘要区包含：

- 企业 Logo
- 企业名称
- 创建时间

建议参数：

| 项目 | 建议值 |
|---|---|
| Logo 尺寸 | `48px ~ 56px` |
| 标题字号 | `18px ~ 20px` |
| 标题字重 | `600` |
| 副标题字号 | `13px ~ 14px` |
| 副标题颜色 | `#A0A0A0` 左右 |
| 标题与副标题间距 | `6px ~ 8px` |

视觉特点：

- 顶部内容采用居中布局
- Logo 与标题构成单一视觉焦点
- 使用非常轻的灰色副文本降低干扰

### 4.2 字段信息区

字段区采用 **左侧图标 + 标签 + 右侧值** 的 CRM 常见表达方式。

典型字段包括：

- URL
- Account Owner
- Address
- ICP
- Revenue
- Linkedin
- Twitter

建议参数：

| 项目 | 建议值 |
|---|---|
| 字段图标尺寸 | `14px ~ 16px` |
| 标签字号 | `13px ~ 14px` |
| 标签颜色 | `#9A9A9A ~ #A3A3A3` |
| 值字号 | `14px` |
| 值颜色 | `#4A4A4A ~ #5A5A5A` |
| 行内左右间距 | `8px` |
| 每行最小高度 | `28px` |

视觉特点：

- 图标全部弱化处理，不抢主信息
- 标签与内容对比明确，但不是强黑白对比
- 整体偏“管理后台密度型 UI”

### 4.3 Tag / Chip 风格

截图中可见 URL、LinkedIn、Twitter 等字段值使用胶囊标签样式。

建议参数：

| 项目 | 建议值 |
|---|---|
| 高度 | `22px ~ 24px` |
| 水平 padding | `8px ~ 10px` |
| 垂直 padding | `2px ~ 4px` |
| 圆角 | `999px` |
| 背景色 | `#F4F4F2 ~ #F6F6F4` |
| 边框色 | `#DCDCD8 ~ #E2E2DE` |
| 字号 | `13px` |
| 文字颜色 | `#5F5F5F` |

适合借鉴点：

- 文本值较长时，使用弱对比 chip 而非链接蓝色文本
- 减少视觉跳出感，让字段区保持平静

## 8. Twenty 表格样式参数整理

> 来源：基于你补充的 Companies table Figma 截图识别。  
> 注意：截图右侧出现的紫色虚线框、紫色边框值和选中态信息，大概率属于 Figma 选区标识，不应直接当作最终产品视觉样式。

### 8.1 设计对象概述

这是一个典型的 **CRM 列表表格 / Data Table**，用于高密度浏览公司数据。

整体风格关键词：

- 极简表格骨架
- 高信息密度
- 弱边框、弱分割
- 行内多类型数据混排
- 支持分组展示

### 8.2 截图中可直接确认的信息

从截图可确认这是一张 `Companies table`，并且包含以下列：

- 选择框
- Companies
- URL
- Created By
- Address
- Account Owner
- ICP
- ARR
- Linkedin
- Industry
- Main contact
- Employees
- Opportunities
- Add field

同时可以确认的结构特征：

| 项目 | 参数 |
|---|---|

| 展示方式 | 按分组展示，如 `Companies (13)`、`Customers` |
| 列头位置 | 顶部固定一行 |
| 数据表现 | 文本 + 图标 + 小头像 + chip 混排 |
| 行操作风格 | 默认弱化，强调内容本身 |
| 分组入口 | 每组顶部一行分组标题 |

### 8.3 按截图推断的表格容器参数

以下为视觉推断值，适合用于 Flutter / Web 复刻：

| 项目 | 建议值 |

| 表头高度 | `32px ~ 36px` |
| 数据行高度 | `28px ~ 32px` |

| 表格首层外边距 | `16px ~ 20px` |
| 分组之间垂直间距 | `16px ~ 24px` |
| 列头到底部内容间距 | `4px ~ 6px` |

如果参考截图右侧 Figma Dev Mode 面板，可作为“容器层”近似值记录：

|---|---|

| Top Padding | `20px` |

### 8.4 表头样式

表头视觉非常克制，主要承担字段索引作用，不争夺注意力。

建议参数：

| 项目 | 建议值 |
|---|---|
| 表头字号 | `12px ~ 13px` |
| 表头字重 | `500` |
| 表头颜色 | `#8D8D8D ~ #989898` |
| 排序图标尺寸 | `10px ~ 12px` |
| 表头背景 | `透明 / 白底` |
| 表头下分隔 | `1px` 极浅灰线 |

适合借鉴点：

- 表头颜色明显弱于正文
- 表头不使用实色背景块
- 列名和排序状态使用极轻图标辅助

### 8.5 数据行样式

从截图看，数据行采用典型的高密度 CRM 浏览样式。

建议参数：

| 项目 | 建议值 |
|---|---|
| 行高 | `30px` 左右 |
| 正文字号 | `12px ~ 13px` |
| 正文字重 | `400` |
| 主文本颜色 | `#444444 ~ #555555` |
| 次级文本颜色 | `#8F8F8F ~ #9C9C9C` |
| Hover 背景 | `#F7F7F5 ~ #F8F8F6` |
| 选中态背景 | `#F3F1FF` 或品牌浅色 |
| 行分隔线 | 很弱，甚至可仅依赖留白 |

视觉特点：

- 横向信息密度高，但因为字体和颜色足够克制，不会太吵
- 每一行更像“信息带”，而不是带强边框的表格条目
- 优先保证扫读效率，而不是表格装饰感

### 8.6 单元格内容模式

这张表最值得借鉴的是单元格内容组织方式，而不是传统表格线。

#### 8.6.1 公司名称列

结构：

- 复选框

- 公司名文本

建议参数：

| 项目 | 建议值 |

| Logo / 圆点图标 | `14px ~ 16px` |
| 公司名字号 | `12px ~ 13px` |
| 公司名字重 | `500` |

#### 8.6.2 URL / 社媒 / 行业等字段

截图中很多字段采用弱对比 chip 显示，例如：

- `stripe`
- `anthropic`
- `facebook`
- 行业标签

建议参数：

| 项目 | 建议值 |
|---|---|

| 字号 | `11px ~ 12px` |
| 左右 padding | `6px ~ 8px` |
| 圆角 | `999px` |
| 背景色 | `#F3F3F1 ~ #F5F5F3` |
| 边框色 | `#E1E1DD` |
| 文字颜色 | `#666666` |

#### 8.6.3 人员字段

如 `Created By`、`Account Owner`、`Main contact` 这些列，采用了“头像 + 名字”的紧凑展示。

建议参数：

| 项目 | 建议值 |
|---|---|
| 头像尺寸 | `14px ~ 18px` |
| 头像与文字间距 | `6px` |
| 名字字号 | `12px ~ 13px` |
| 名字颜色 | `#555555` |

#### 8.6.4 数值字段

如 `ARR`、`Employees`、`Opportunities` 等字段偏向右侧对齐，便于纵向比较。

建议参数：

| 项目 | 建议值 |
|---|---|
| 数值字号 | `12px ~ 13px` |
| 数值颜色 | `#4B4B4B` |
| 对齐方式 | `Right` 更优 |
| 金额字段格式 | `$500,000` 这种短格式 |

### 8.7 分组样式

截图里表格明显支持按组展示，例如：

- `Companies (13)`
- `Customers`

建议参数：

| 项目 | 建议值 |
|---|---|
| 分组标题字号 | `12px ~ 13px` |
| 分组标题字重 | `500 ~ 600` |
| 标题颜色 | `#7B7B7B ~ #878787` |
| 分组计数字号 | 同标题或略浅 |

适合借鉴点：

- 分组标题不抢视觉焦点，但足够明确
- 让大表格具备信息块结构，减轻用户浏览疲劳

### 8.9 对 Locus 可迁移的落地建议

这套表格风格特别适合你项目里这几类场景：

- CRM 联系人表
- 公司 / 客户列表
- 合同列表
- 时间线对象列表

## 9. 这套设计最值得借鉴的元素

如果你是为了借鉴页面设计元素，我建议优先拿这几个点：

1. **320px 固定详情侧栏**
   - 很适合桌面端 CRM / 知识库 / 详情页布局。

2. **轻边框 + 低对比背景**
   - 不靠重阴影，而靠 `1px` 分隔线和浅灰底色建立层次。

3. **顶部实体摘要区**
   - Logo + 名称 + 时间信息的结构很稳，适合联系人、公司、项目、合同等实体页。

4. **字段列表弱化图标**
   - 图标只是提示，不抢文字信息，适合高密度业务型界面。

5. **Section 化组织关联数据**
   - 比直接堆字段更清晰，特别适合你后续做 CRM / 项目 / 知识对象详情页。

6. **Chip 化的文本值展示**
   - 很适合域名、标签、社媒链接、状态等内容。

## 10. 对 Locus 可迁移的落地建议

结合你当前项目，这个设计可以直接迁移为以下场景：

- 联系人详情侧栏
- 公司 / 客户详情侧栏
- 时间线对象详情面板
- 知识条目元信息面板
- 合同 / 商机详情页右侧信息栏

推荐保留的核心特征：

- 固定宽度：`320px`
- 面板 padding：`16px`
- 模块分隔线：`1px`
- 标题层级清晰但不过度强调

不建议照搬的点：

- 当前截图整体略偏“后台管理系统感”，如果直接用于 Locus 主界面，可能会显得偏硬、偏密
- 如果用于移动端，需要把固定侧栏改成抽屉或底部详情面板

## 11. 结论

- **320px 固定侧栏**
- **16px 内边距**
- **#FCFCFC 面板底色**
- **#EBEBE8 细分隔线**
- **30px 左右高密度表格行**
- **14px 主体正文**
- **18~20px 实体标题**
- **Section 化组织关联内容**
- **弱对比 chip 与图标系统**
- **按组展示的大表格结构**
